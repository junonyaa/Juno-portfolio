## Featured project

**Pocket Survivor** is a top-down survivor-like 2D game prototype made with Godot and GDScript. It includes combat, enemy waves, increasing difficulty, gem collection, leveling, and upgrade choices.

## Website features

- Responsive dark, colorful, minimalist design
- Embedded gameplay video
- Pocket Survivor screenshot gallery
- Full-screen screenshot viewer with previous/next navigation
- Keyboard navigation with the left and right arrow keys
- GitHub Pages deployment
